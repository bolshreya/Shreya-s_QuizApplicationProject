# Python Quiz Application

A simple command-line quiz application built with Python. It tests basic Python and programming knowledge through multiple-choice questions and shows a detailed result at the end.

## Features

- Menu-driven interface (Start Quiz, Instructions, Exit)
- 5 multiple-choice questions with 4 options each
- Input validation (accepts only A, B, C or D)
- Instant feedback after every answer
- Final score, percentage and count of correct and incorrect answers
- Answer review showing your answer and the correct answer

## Technologies Used

- Python 3

## How to Run

1. Make sure Python 3 is installed on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```
python quiz.py
```

## How to Play

1. Choose option 1 from the main menu to start the quiz.
2. Read each question and type A, B, C or D.
3. You will see right away whether your answer was correct.
4. At the end, view your score, percentage and answer review.

## Scoring

- Each correct answer gives 1 mark.
- There is no negative marking.
